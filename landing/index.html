01 // PRINCIPIOS

Diseñado para la Autonomía Real

Monocrom no es una ventana de chat ni un juguete de respuestas rápidas. Es un entorno de trabajo formal donde cada rol tiene responsabilidades, jerarquías y herramientas de ejecución.

I.

Estructura Organizacional

Tú defines el organigrama. El Director general delega subtareas a los especialistas de desarrollo, diseño y QA, quienes se coordinan entre sí mediante protocolos de traspaso (handoff) y revisión mutua.

MULTI-AGENT COLLABORATION
II.

Memoria y Aprendizaje Local

Bases de datos vectoriales (ChromaDB) y relacionales (SQLite) en tu propio disco duro. Tus agentes recuerdan decisiones de semanas pasadas, estilos de código y contextos sin enviar tus datos a la nube.

100% LOCAL PRIVACY
III.

Navegación y Herramientas Reales

Los agentes no solo devuelven texto; abren navegadores reales con Playwright, extraen datos web en vivo, ejecutan scripts de terminal, compilan código y generan documentos de Office (.docx, .xlsx, .pptx).

BROWSER & SHELL RUNTIME

04 // TRANSPARENCIA

Preguntas Frecuentes

Toda la infraestructura de Monocrom se ejecuta en tu computadora: base de datos SQLite, memoria vectorial ChromaDB, navegador Playwright y archivos generados. Nada de tu código, chats o documentos se envía a nuestros servidores. Solo las llamadas a las APIs de IA (OpenAI, Claude, etc.) viajan a los proveedores que tú elijas.

Sí. Monocrom cuenta con soporte nativo para Ollama y vLLM. Puedes correr modelos locales como Llama 3.3, Mistral o DeepSeek directamente en tu hardware sin costo por token.

Monocrom incluye un protocolo de colaboración multi-agente. Cuando un rol directivo asigna una tarea, el sistema genera subtareas en el tablero Kanban y envía las dependencias a los especialistas. Los agentes se pasan resultados intermedios, realizan revisiones entre pares (Peer Review) y sólo marcan la tarea como completada cuando el revisor la aprueba.

Monocrom incluye adaptadores para correo electrónico (IMAP/SMTP), WhatsApp, Telegram, Slack, Discord y el estándar abierto MCP (Model Context Protocol) para conectar cualquier base de datos o API corporativa.
